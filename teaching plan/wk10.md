รหัสวิชา (Code)     21901-2003  	วิชา (Subject)     การพัฒนาเว็บแอปพลิเคชัน                                                        
หน่วยที่ (Unit)       5		ชื่อหน่วย (Name of Unit)     Midterm + State (สอบกลางภาคและการจัดการสถานะ)
หัวเรื่อง (Sub Unit)/งาน (JOB) การจัดการ State ขั้นสูง (Props Drilling และ Context API)

1.  สาระสำคัญ (Concept) 
	ในการพัฒนาเว็บแอปพลิเคชันที่มีความซับซ้อน มักจะพบปัญหา Props Drilling ซึ่งคือการส่งผ่านข้อมูล (Props) จาก Component แม่ไปยัง Component ลูกที่อยู่ลึกมากๆ ผ่าน Component อื่นๆ ที่ไม่ได้ใช้งานข้อมูลนั้น ทำให้โค้ดอ่านยากและจัดการยาก วิธีแก้ไขคือการใช้ Context API ที่เปรียบเสมือนตัวแปรส่วนกลาง (Global State) ที่ทำให้ทุก Component สามารถเรียกใช้ข้อมูลได้โดยตรงผ่าน `useContext` เช่น การจัดการข้อมูลผู้ใช้งานที่ล็อกอิน (AuthContextType)

2.  สมรรถนะหลัก/ย่อย (Unit of Competence / Element of Competence)
1. มีความเข้าใจปัญหาของการส่งข้อมูลแบบ Props Drilling และแนวทางแก้ไข
2. มีความเข้าใจหลักการทำงานของ Context API (Provider และ Consumer)
3. มีทักษะในการสร้าง `createContext` และใช้งาน `useContext` เพื่อแชร์ State
4. มีเจตคติและกิจนิสัยที่ดีในการปฏิบัติงานด้วยความละเอียดรอบคอบ รับผิดชอบ

3.  จุดประสงค์เชิงพฤติกรรม (Behavioral Objective)
1. อธิบายปัญหา Props Drilling (เมื่อไหร่ควร Lift State ขึ้นไปไว้ที่ parent) ได้
2. สร้าง Context ด้วย `createContext<T>` ร่วมกับ TypeScript Interface ได้อย่างถูกต้อง
3. ประยุกต์ใช้ Context Provider เพื่อกระจายข้อมูลไปยัง Component ย่อยได้
4. ดึงข้อมูลจาก Context มาใช้งานผ่าน `useContext` ได้อย่างถูกต้อง
5. เตรียมเครื่องคอมพิวเตอร์และสภาพแวดล้อมเพื่อการเรียนได้
6. เปิดโปรแกรมหรือเอกสารเพื่อศึกษาเนื้อหาควบคู่ได้อย่างถูกต้อง
7. สรุปเนื้อหาได้
8. แสดงความสนใจต่องานที่ได้รับมอบหมายได้เป็นอย่างดีเมื่อครูมอบหมายงานให้ทำ
9. ประยุกต์แนวทางการพัฒนาแบบเศรษฐกิจพอเพียงในเรื่องการประหยัดอดออมในการใช้อุปกรณ์อย่างรู้คุณค่า
10. ประยุกต์ใช้เป็นแนวทางในการดำเนินชีวิตอย่างสุจริตได้
5.  กิจกรรมการเรียนรู้ (Teaching / Learning Activities)
	-  แจ้งผลการสอบกลางภาค และอธิบายการเชื่อมโยงเข้าสู่เนื้อหาครึ่งภาคเรียนหลัง
	เรื่องที่/งานที่ (Sub Topic/Job)  :   การจัดการ State ขั้นสูง
	หัวข้อที่/งานที่ (Sub  Unit/Main Job)  :  Props Drilling และ Context API
	ขั้นนำเข้าสู่บทเรียน  (Motivation)  
1. ครูตั้งคำถามว่า หากหน้าจอ Header ต้องการแสดงชื่อผู้ใช้งานที่ล็อกอิน แต่ข้อมูลนี้อยู่ที่ App (Component หลักสุด) เราจะส่งข้อมูลลงไปที่ Header อย่างไร
2. ครูสาธิตการส่ง Props ลงไป 3-4 ชั้น (Props Drilling) และให้นักเรียนดูว่าโค้ดมีความซับซ้อนแค่ไหน
3. ครูสรุปเข้าเรื่อง Context API ว่าเป็นเสมือน "ระบบประกาศเสียงตามสาย" ที่ไม่ต้องฝากใครไปบอก แต่ทุกคนได้ยินพร้อมกัน
	ขั้นการให้เนื้อหาความรู้  (Information)  
1. ขอบข่ายเนื้อหาหลัก
Props Drilling: ข้อจำกัดของ Local State เมื่อมี Component ซ้อนกันหลายชั้น และแนวทางการทำ State Lifting
Context API: การสร้าง Global State ด้วย `createContext()`, การห่อหุ้มแอปพลิเคชันด้วย Provider
useContext: การดึงข้อมูลส่วนกลางมาใช้ และการกำหนด TypeScript Type (เช่น `AuthContextType`)
2. แนวทางการจัดกิจกรรมการสอน
2.1 จัดเตรียมเนื้อหาให้นักศึกษา (`wk5-content1-props.md`, `wk5-content2-context.md`)
2.2 ถามและตอบคำถามนักเรียนพร้อมกับบรรยายเนื้อหาและยกตัวอย่าง
2.3 สาธิตการสร้าง AuthContext เพื่อเก็บข้อมูล User แบบง่ายๆ
2.4 อธิบายกระบวนการเรียกใช้ `useContext` ใน Component ลูก
ขั้นการประยุกต์เนื้อหา  (Application) 
1. ให้ นศ. ศึกษาเนื้อหาและทดลองสร้าง `ThemeContext` หรือ `AuthContext` ขึ้นมาใช้งาน
2. ให้ นศ. นำ Provider ไปหุ้ม Component หลัก (`<App>`)
3. ให้ นศ. ใช้ `useContext` ใน Component ที่อยู่ลึกๆ เพื่อดึงข้อมูลมาแสดงผล
		-  สุ่มถามผู้เรียนว่าข้อควรระวังในการนำทุกอย่างไปใส่ใน Context API คืออะไร (เช่น ปัญหา Re-render บ่อย)

	ขั้นตรวจผลสำเร็จ  (Progress)
- ผู้เรียนและครูผู้สอนตรวจสอบผลลัพธ์การแสดงชื่อ User บนหน้าจอโดยไม่ได้ผ่าน Props
- การสรุปสาระสำคัญลงในสมุดจด  ครูผู้สอนตรวจสอบจากการถาม-ตอบของผู้เรียน

แผ่นที่ :
การจัดการ State ขั้นสูง (Props Drilling และ Context API)
- **Props Drilling** เป็นปัญหาที่เกิดขึ้นเมื่อต้องการส่ง State จาก Component ต้นทางไปยัง Component ปลายทาง แต่ต้องส่งผ่าน Props ทะลุ Component ตัวกลางหลายๆ ชั้นที่ไม่ได้ใช้ข้อมูลนั้น ทำให้โค้ดรุงรังและแก้ไขยาก
- **State Lifting** คือเทคนิคการขยับ State ขึ้นไปไว้ที่ Component แม่ที่ใช้ร่วมกัน แต่วิธีนี้ก็อาจก่อให้เกิด Props Drilling ได้หากต้องส่งกลับลงไปลึกๆ 
- **Context API** เป็นตัวช่วยของ React ที่ทำหน้าที่เป็นพื้นที่ส่วนกลาง (Global State) ให้เราสามารถเก็บข้อมูลที่ต้องใช้ร่วมกันหลายๆ หน้า (เช่น ข้อมูล User, Theme สี) ไว้ตรงกลาง จากนั้น Component ใดๆ ก็ตามที่ถูกครอบด้วย `<Provider>` จะสามารถดึงข้อมูลเหล่านั้นไปใช้ได้ทันทีด้วย Hook ที่ชื่อว่า `useContext` โดยไม่ต้องรับผ่าน Props อีกต่อไป
