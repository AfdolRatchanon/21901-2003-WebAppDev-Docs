แผนการสอนแบบฐานสมรรถนะ (Competency-based Teaching Plan)
สัปดาห์ที่ (Week)     9

รหัสวิชา (Code)     21901-2003  	วิชา (Subject)     การพัฒนาเว็บแอปพลิเคชัน                                                        
หน่วยที่ (Unit)       5		ชื่อหน่วย (Name of Unit)     Midterm + State (สอบกลางภาคและการจัดการสถานะ)
หัวเรื่อง (Sub Unit)/งาน (JOB) สอบกลางภาคและการนำเสนอโปรเจกต์

1.  สาระสำคัญ (Concept) 
	สัปดาห์นี้จะเป็นการวัดผลและประเมินผลกลางภาคเรียน (Midterm Exam) เพื่อตรวจสอบความรู้ความเข้าใจและทักษะการปฏิบัติงานที่นักศึกษาได้เรียนรู้มาตั้งแต่สัปดาห์ที่ 1-8 ซึ่งครอบคลุมตั้งแต่โครงสร้างพื้นฐาน การจัดการ Form, State, TypeScript, Tailwind CSS และการเชื่อมต่อ API ตลอดจนมีการให้นักศึกษานำเสนอความคืบหน้าของระบบเบิก-จ่ายอุปกรณ์ไอที (Project Presentation)

2.  สมรรถนะหลัก/ย่อย (Unit of Competence / Element of Competence)
1. มีความเข้าใจและสามารถสรุปองค์ความรู้การพัฒนาเว็บแอปพลิเคชันในครึ่งภาคเรียนแรกได้
2. มีทักษะในการประยุกต์ใช้ความรู้ที่ผ่านมาแก้ไขโจทย์ปัญหาในข้อสอบภาคปฏิบัติได้
3. มีทักษะในการนำเสนอผลงาน (Presentation) และการสื่อสาร
4. มีความซื่อสัตย์สุจริตในการสอบ และความรับผิดชอบในการนำเสนอผลงาน

3.  จุดประสงค์เชิงพฤติกรรม (Behavioral Objective)
1. ทำแบบทดสอบวัดผลสัมฤทธิ์ทางการเรียนกลางภาคได้อย่างถูกต้อง
2. นำเสนอความคืบหน้าของโปรเจกต์ (ระบบเบิก-จ่ายอุปกรณ์) และตอบคำถามได้อย่างชัดเจน
3. วิเคราะห์และแก้ไขปัญหาจากโจทย์ที่กำหนดให้ในการสอบปฏิบัติได้
4. เตรียมเครื่องคอมพิวเตอร์และสภาพแวดล้อมสำหรับการสอบได้
5. เปิดโปรแกรมและปฏิบัติตามกฎเกณฑ์การสอบได้อย่างถูกต้อง
6. แสดงความสนใจต่องานที่ได้รับมอบหมายได้เป็นอย่างดีเมื่อครูมอบหมายงานให้ทำ
7. ประยุกต์แนวทางการพัฒนาแบบเศรษฐกิจพอเพียงในเรื่องการประหยัดอดออมในการใช้อุปกรณ์อย่างรู้คุณค่า
8. ประยุกต์ใช้เป็นแนวทางในการดำเนินชีวิตอย่างสุจริตได้
5.  กิจกรรมการเรียนรู้ (Teaching / Learning Activities)
	-  แจ้งกฎกติกาการสอบกลางภาคและการนำเสนอโปรเจกต์
	เรื่องที่/งานที่ (Sub Topic/Job)  :   การวัดผลกลางภาคเรียน
	หัวข้อที่/งานที่ (Sub  Unit/Main Job)  :  สอบกลางภาคและการนำเสนอโปรเจกต์
	ขั้นนำเข้าสู่บทเรียน  (Motivation)  
1. ครูชี้แจงความสำคัญของการสอบกลางภาคว่าเป็นการทบทวนตนเอง และการนำเสนอโปรเจกต์คือการฝึกทักษะการทำงานจริง (Soft Skills)
2. ครูให้กำลังใจและเปิดโอกาสให้นักเรียนซักถามข้อสงสัยก่อนเริ่มการประเมิน
	ขั้นการให้เนื้อหาความรู้  (Information)  
1. ขอบข่ายการประเมิน
สอบปฏิบัติ (Practical Exam): ทบทวนการสร้าง Component, การใช้ Types/Interfaces, การเชื่อมต่อ API
สอบทฤษฎี (Theory Exam): ทฤษฎีเรื่อง State, JSX, Promises, Async/Await
นำเสนอโปรเจกต์ (Project Defense): นำเสนอหน้าจอที่ทำเสร็จแล้ว (UI, Form, API Fetching) พร้อมอธิบายโค้ด
2. แนวทางการจัดกิจกรรมการสอน
2.1 แจกแจงข้อสอบและกระดาษคำตอบ/ระบบสอบออนไลน์ให้นักศึกษา (`wk5-midterm-exam.md`)
2.2 ควบคุมการสอบให้เป็นไปด้วยความเรียบร้อย
2.3 จัดลำดับคิวการนำเสนอโปรเจกต์
ขั้นการประยุกต์เนื้อหา  (Application) 
1. ให้ นศ. ทำการสอบภาคทฤษฎีและภาคปฏิบัติ
2. ให้ นศ. แต่ละคน/กลุ่ม นำเสนอผลงานหน้าชั้นเรียน และตอบคำถาม Code Interview จากผู้สอน
		-  สุ่มถามคำถามสัมภาษณ์ (Code Interview) จากโค้ดที่นักศึกษาใช้ในโปรเจกต์

	ขั้นตรวจผลสำเร็จ  (Progress)
- ครูผู้สอนรวบรวมคะแนนสอบ และประเมินผลการนำเสนอ
- แจ้งผลการประเมินเบื้องต้นและจุดที่ต้องนำไปปรับปรุงในครึ่งภาคเรียนหลัง

6.  การบูรณาการ (Integration)
6.1  เนื้อหาที่บูรณาการ (Content)
		- การบูรณาการภาษาอังกฤษ (CLIL) ในการใช้คำศัพท์เทคนิคอธิบายการทำงานของโค้ดระหว่างการนำเสนอ
	6.2  ขั้นตอนการจัดทำ (Process)
		- การนำเสนอโปรเจกต์ (Project-Based Learning) เพื่อจำลองสถานการณ์การส่งมอบงานในบริษัทซอฟต์แวร์
7.  สื่อ – อุปกรณ์ (Materials) 
ใบข้อสอบภาคทฤษฎีและปฏิบัติ (Midterm Exam) (`wk5-midterm-exam.md`)
แบบประเมินผลการนำเสนอโปรเจกต์
เครื่องคอมพิวเตอร์และโปรเจคเตอร์สำหรับการนำเสนอ
8.  การวัด และประเมินผล (Measurement and Evaluation)
การสังเกตพฤติกรรมความซื่อสัตย์สุจริตระหว่างการสอบ
คะแนนจากแบบทดสอบกลางภาค (ทฤษฎีและปฏิบัติ)
คะแนนจากแบบประเมินการนำเสนอโปรเจกต์ (การทำงานของแอปพลิเคชัน, ความเข้าใจโค้ด, การตอบคำถาม)
9.  กิจกรรมเสนอแนะ (Optional Activities)
	- ให้ผู้เรียนที่นำเสนอเสร็จแล้วเข้าประเมินผลงานของเพื่อน (Peer Review) เพื่อแลกเปลี่ยนความคิดเห็น
