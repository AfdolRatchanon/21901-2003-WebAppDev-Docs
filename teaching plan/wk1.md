แผนการสอนแบบฐานสมรรถนะ (Competency-based Teaching Plan)
สัปดาห์ที่ (Week)     1

รหัสวิชา (Code)     21901-2003  	วิชา (Subject)     การพัฒนาเว็บแอปพลิเคชัน                                                        
หน่วยที่ (Unit)       1		ชื่อหน่วย (Name of Unit)     โครงสร้างพื้นฐาน (React.ts + Vite)
หัวเรื่อง (Sub Unit)/งาน (JOB) การติดตั้งโปรเจกต์ โครงสร้างพื้นฐาน JSX และ Prompt Engineering

1.  สาระสำคัญ (Concept) 
	การพัฒนาเว็บแอปพลิเคชันสมัยใหม่นิยมใช้ไลบรารี React ร่วมกับ Vite เพื่อความรวดเร็วในการพัฒนา และใช้ TypeScript เพื่อช่วยในการตรวจสอบชนิดข้อมูล (Type Checking) ลดข้อผิดพลาด นอกจากนี้ยังรวมถึงการใช้ JSX สำหรับการเขียนโค้ด UI การใช้คำสั่งเงื่อนไข (Conditional Rendering) การวนซ้ำเพื่อแสดงผลข้อมูลแบบรายการ (.map()) และการประยุกต์ใช้ปัญญาประดิษฐ์ (AI) ในการเขียน Prompt อย่างมีโครงสร้างเพื่อช่วยในการแก้ไขปัญหา (Debug) และเรียนรู้การเขียนโค้ดได้อย่างมีประสิทธิภาพ

2.  สมรรถนะหลัก/ย่อย (Unit of Competence / Element of Competence)
1. มีความเข้าใจเกี่ยวกับหลักการพัฒนาเว็บแอปพลิเคชันด้วยโปรแกรมภาษาคอมพิวเตอร์ (React, Vite, TypeScript)
2. มีความเข้าใจหลักการทำงานของ JSX (Conditional Rendering และ Map)
3. มีความเข้าใจในการประยุกต์ใช้ AI เพื่อช่วยในการเขียนโค้ด
4. มีทักษะพื้นฐานในการติดตั้ง รันโปรเจกต์ React และจัดการโครงสร้างไฟล์

3.  จุดประสงค์เชิงพฤติกรรม (Behavioral Objective)
1. สร้างโปรเจกต์ React + Vite + TypeScript และรันคำสั่ง npm run dev ได้อย่างถูกต้อง
2. อธิบายโครงสร้างของแฟ้มข้อมูล (Folder Structure) และ Basic Types ใน TypeScript ได้
3. อธิบายและใช้งาน JSX รวมถึง `.map()` เพื่อแสดงผลรายการและเงื่อนไขได้อย่างถูกต้อง
4. ประยุกต์ใช้ 4-part prompt ของ AI ในการช่วยแก้ปัญหา (Debug) TypeScript Error ได้
5. เตรียมเครื่องคอมพิวเตอร์และสภาพแวดล้อมเพื่อการเรียนได้
6. เปิดโปรแกรม GoogleClassroom หรือเอกสาร (Docs) เพื่อศึกษาเนื้อหาควบคู่ได้อย่างถูกต้อง
7. สรุปเนื้อหาได้
8. แสดงความสนใจต่องานที่ได้รับมอบหมายได้เป็นอย่างดีเมื่อครูมอบหมายงานให้ทำ
9. ประยุกต์แนวทางการพัฒนาแบบเศรษฐกิจพอเพียงในเรื่องการประหยัดอดออมในการใช้อุปกรณ์อย่างรู้คุณค่า
10. ประยุกต์ใช้เป็นแนวทางในการดำเนินชีวิตอย่างสุจริตได้
5.  กิจกรรมการเรียนรู้ (Teaching / Learning Activities)
	-  ปฐมนิเทศรายวิชา (Course Orientation) และอธิบายระบบ MIAP
	เรื่องที่/งานที่ (Sub Topic/Job)  :   โครงสร้างพื้นฐาน (React + Vite + TypeScript)
	หัวข้อที่/งานที่ (Sub  Unit/Main Job)  :  การติดตั้งโปรเจกต์ โครงสร้างพื้นฐาน JSX และ Prompt Engineering
	ขั้นนำเข้าสู่บทเรียน  (Motivation)  
1. ครูอธิบายภาพรวมของรายวิชา นโยบายการสอนแบบ Code-First และโปรเจกต์ระบบเบิก-จ่ายอุปกรณ์ไอที (IT Equipment Checkout System)
2. ครูถามนักเรียนเกี่ยวกับประสบการณ์การพัฒนาเว็บ และเครื่องมือที่เคยใช้
3. ครูสรุปเข้าเรื่องความสำคัญของการใช้เทคโนโลยีสมัยใหม่ (React, Vite, TypeScript) ในการทำงานจริง
	ขั้นการให้เนื้อหาความรู้  (Information)  
1. ขอบข่ายเนื้อหาหลัก
โครงสร้างโปรแกรม (React + Vite + TypeScript): แนะนำการติดตั้ง โครงสร้างโฟลเดอร์การทำงาน ไฟล์ main.tsx พื้นฐานการแสดงผล และการใช้งาน Basic Types (string, number, boolean) สำหรับ TypeScript
JSX + Conditional Rendering: อธิบายไวยากรณ์ JSX การเขียนเงื่อนไขเพื่อแสดงผลที่แตกต่างกัน และการใช้ฟังก์ชัน `.map()` สำหรับแสดงข้อมูลแบบรายการ
AI & Prompt Engineering: เทคนิคการเขียน Prompt แบบ 4 ส่วน (4-part prompt) และวิธีการถาม AI เพื่อช่วยแก้ Error (Debug)
2. แนวทางการจัดกิจกรรมการสอน
2.1 จัดเตรียมเนื้อหาเรื่องโครงสร้างพื้นฐานให้นักศึกษา (wk1-content1-intro, wk1-content2-jsx, wk1-content3-ai)
2.2 ถามและตอบคำถามนักเรียนพร้อมกับบรรยายเนื้อหา นโยบายหลักสูตร แบบ Code-First
2.3 สาธิตการสร้างโปรเจกต์ React + Vite ให้นักเรียนทำตาม และทดลองใช้ AI ช่วยแก้ไขโค้ด
2.4 อธิบายหรือสาธิตการทำงานซ้ำเมื่อนักเรียนทำไม่ทัน
ขั้นการประยุกต์เนื้อหา  (Application) 
1. ให้ นศ. ศึกษาเนื้อหาและทดลองสร้างโปรเจกต์
2. ให้ นศ. ทดลองใช้งาน JSX เพื่อแสดง badge สีตามเงื่อนไข
3. ให้ นศ. ทดลองใช้ AI แก้ไขปัญหา Error ที่จำลองขึ้นมา
		-  สุ่มถามผู้เรียนว่าในมุมมองของผู้เรียน การใช้เครื่องมืออย่าง Vite สะดวกกว่ารูปแบบเก่าอย่างไร และเทคนิค Prompt Engineering มีประโยชน์ต่อการเขียนโค้ดอย่างไร

	ขั้นตรวจผลสำเร็จ  (Progress)

แผ่นที่ :
การติดตั้งโปรเจกต์ โครงสร้างพื้นฐาน JSX และ Prompt Engineering
- React เป็นไลบรารี JavaScript ที่ใช้สร้าง User Interface (UI) โดยมีเครื่องมืออย่าง Vite ช่วยให้การประมวลผลและการรันระบบจำลองการพัฒนา (Dev Server) ทำได้เร็วขึ้น
- การเขียนโปรแกรมจะใช้ TypeScript ควบคู่ไปกับ React เพื่อระบุชนิดข้อมูล (Type) ให้ชัดเจน ช่วยลดข้อผิดพลาดขณะเขียนโค้ด (Type Checking) เช่น การระบุประเภทข้อมูล `string`, `number`, `boolean`
- JSX เป็นไวยากรณ์ที่ผสมผสาน HTML เข้าไปใน JavaScript ได้เลย ทำให้สามารถแทรกตัวแปร คำสั่งเงื่อนไข (Conditional Rendering) เพื่อใช้สำหรับเปลี่ยนสี Badge หรือจัดการข้อมูล และสามารถใช้ฟังก์ชันวนซ้ำอย่าง `.map()` ในการนำข้อมูลมาแสดงผลแบบรายการหน้าจอได้
- การใช้ ปัญญาประดิษฐ์ (AI) เพื่อเป็นผู้ช่วยในการเขียนโปรแกรม ควรใช้เทคนิคที่เรียกว่า 4-part prompt ประกอบด้วย Context (บริบท), Task (สิ่งที่ต้องการให้ทำ), Instructions (เงื่อนไขและรายละเอียด), และ Output Format (รูปแบบผลลัพธ์) เพื่อให้ได้คำตอบที่ถูกต้องที่สุด โดยเฉพาะเวลานำไปใช้แก้ไขข้อผิดพลาด (Debug)
