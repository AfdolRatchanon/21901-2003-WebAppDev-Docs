1.  สาระสำคัญ (Concept) 
	หัวใจสำคัญของการพัฒนาเว็บด้วย React คือการแบ่งหน้าจอออกเป็นส่วนย่อยๆ ที่เรียกว่า Component ซึ่งสามารถนำกลับมาใช้ซ้ำได้ การส่งข้อมูลระหว่าง Component จะทำผ่านสิ่งที่เรียกว่า Props และในการเขียน TypeScript จำเป็นต้องมีการกำหนดรูปแบบข้อมูลของ Props เหล่านั้นด้วย Interface อย่างชัดเจนเพื่อความถูกต้อง นอกจากนี้ยังมีการประยุกต์ใช้การทำ Conditional Rendering (การแสดงผลตามเงื่อนไข) เพื่อเปลี่ยนสี Status Badge ตามสถานะที่รับเข้ามา ปฏิบัติการนี้จะเน้นไปที่การประยุกต์ใช้ความรู้มาสร้างคอมโพเนนต์สำหรับการ์ดอุปกรณ์ (EquipmentCard) ในโปรเจกต์ระบบเบิก-จ่ายอุปกรณ์ไอที

2.  สมรรถนะหลัก/ย่อย (Unit of Competence / Element of Competence)
1. มีทักษะในการพัฒนาเว็บแอปพลิเคชันด้วยการสร้างและใช้งาน Component ใน React
2. มีทักษะในการกำหนด Interface และส่งข้อมูลผ่าน Props ใน TypeScript
3. มีความสามารถในการประยุกต์ใช้เงื่อนไขเพื่อแสดงผล Status Badge
4. มีเจตคติและกิจนิสัยที่ดีในการปฏิบัติงานด้วยความละเอียดรอบคอบ รับผิดชอบ

3.  จุดประสงค์เชิงพฤติกรรม (Behavioral Objective)
1. สร้าง Component ใหม่ (EquipmentCard) ได้อย่างถูกต้อง
2. กำหนด Interface สำหรับ Props และรับค่าเพื่อแสดงผลได้อย่างถูกต้อง
3. แสดง Status Badge ที่เปลี่ยนสีตามเงื่อนไข (status) ของอุปกรณ์ได้อย่างถูกต้อง
4. ปฏิบัติงานตามนโยบาย Lab โดยการแสดงชื่อและรหัสนักเรียนใน `<footer>` บนหน้าเว็บได้
5. ส่งงานโดยการ Push โค้ดขึ้น GitHub Repository ส่วนตัวและเขียนสรุปได้อย่างถูกต้อง
6. ประเมินผลงานและหาข้อผิดพลาดที่พบระหว่างการทำงานได้
7. แสดงความสนใจต่องานที่ได้รับมอบหมายได้เป็นอย่างดีเมื่อครูมอบหมายงานให้ทำ
8. ประยุกต์แนวทางการพัฒนาแบบเศรษฐกิจพอเพียงในเรื่องการประหยัดอดออมในการใช้อุปกรณ์อย่างรู้คุณค่า
9. ประยุกต์ใช้เป็นแนวทางในการดำเนินชีวิตอย่างสุจริตได้

1. ขอบข่ายเนื้อหาหลัก
Component + Props: การสร้างฟังก์ชันเพื่อทำหน้าที่เป็น UI Component และการส่งผ่านข้อมูลจาก Component แม่ไปยัง Component ลูก
Interface ใน TypeScript: การระบุประเภทข้อมูลสำหรับ Props เช่น `interface EquipmentProps { name: string; status: string; }` เพื่อให้โปรแกรมสามารถตรวจสอบชนิดข้อมูลได้
Status Badge: การประยุกต์ใช้ Conditional Rendering เพื่อกำหนดสี Badge หรือ Class ให้สัมพันธ์กับ Status ที่รับมาทาง Props

- **Component** คือส่วนประกอบของหน้าจอที่ถูกแยกการทำงานออกมาเป็นฟังก์ชันเดี่ยว เพื่อให้สามารถนำกลับมาใช้ซ้ำ (Reusable) โดยไม่ต้องเขียนโค้ดใหม่ทั้งหมด ลดความซ้ำซ้อนของการทำงาน
- **Props (Properties)** คือช่องทางในการส่งผ่านข้อมูลจาก Component ภายนอก (Parent) เข้าสู่ Component ภายใน (Child) เพื่อให้ Component สามารถนำข้อมูลนั้นไปแสดงผลหรือจัดการต่อไปได้
- **Interface** ใน TypeScript ใช้สำหรับนิยามโครงสร้างและชนิดข้อมูล (Type) ที่จำเป็นต้องมี ทำให้การส่ง Props เป็นไปอย่างปลอดภัย (Type-Safety) หากส่งข้อมูลที่ชนิดไม่ถูกต้อง หรือขาดหายไประบบจะแจ้งเตือน
- **การจัดการ Status Badge** เป็นการใช้ Conditional Rendering ร่วมกับการเปลี่ยน Class ของ CSS เพื่อให้สีของ Badge บนหน้าเว็บเปลี่ยนไปตามค่าข้อมูลสถานะ (status) ที่ได้รับมา เช่น หากอุปกรณ์ "ใช้งานได้" เป็นสีเขียว หาก "ส่งซ่อม" เป็นสีแดง
