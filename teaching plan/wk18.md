หัวเรื่อง (Sub Unit)/งาน (JOB) สอบปลายภาค (Final Exam - การวัดสมรรถนะรวบยอด)

1.  สาระสำคัญ (Concept) 
	การสอบปลายภาค (Final Exam) เป็นการวัดประเมินผลสมรรถนะรวบยอดของผู้เรียนตลอดระยะเวลา 18 สัปดาห์ ครอบคลุมความรู้และทักษะด้าน Frontend Development โดยเน้นไปที่ทักษะการอ่านโค้ด (Code Reading) การเขียนโค้ดเพื่อแก้ปัญหา (Code Writing) และความเข้าใจเชิงแนวคิด (Conceptual Understanding) ของเทคโนโลยี React, TypeScript, การจัดการ State แบบต่างๆ, การเชื่อมต่อ API (Axios), การทำ Authentication, และระบบ Real-time (Socket.io) ตามมาตรฐานอาชีพ TPQI 10302

2.  สมรรถนะหลัก/ย่อย (Unit of Competence / Element of Competence)
1. มีทักษะในการอ่านและวิเคราะห์ Source Code (Code Reading) เพื่อระบุการทำงานและข้อบกพร่องได้
2. มีทักษะในการเขียนโปรแกรม (Code Writing) เพื่อสร้าง Component, Custom Hook หรือเชื่อมต่อ API ตามข้อกำหนดได้
3. มีความเข้าใจเชิงแนวคิด (Conceptual) ด้านสถาปัตยกรรมและการทำงานของ Web Application ยุคใหม่
4. มีความสามารถในการประเมินตนเอง (Self-Assessment) และวางแผนพัฒนาทักษะวิชาชีพในอนาคต

3.  จุดประสงค์เชิงพฤติกรรม (Behavioral Objective)
1. วิเคราะห์การทำงานของ React Hooks (`useState`, `useEffect`, `useCallback`) จากโค้ดตัวอย่างได้อย่างถูกต้อง
2. อธิบายความแตกต่างและการนำไปใช้งานของ TypeScript Types และ Interfaces ได้
3. เขียนโค้ดสร้าง React Component ตาม Specification ที่กำหนดให้ทำงานได้อย่างถูกต้อง
4. อธิบายหลักการทำงานของ Context API, JWT, และ Axios Interceptor ได้
5. ดำเนินการสอบปลายภาคภาคปฏิบัติ (Mini Project / Code Writing) ได้ลุล่วงตามเวลาที่กำหนด
6. ส่งงานผ่าน GitHub Repository พร้อมบันทึกสรุปการประเมินตนเองได้
7. แสดงความซื่อสัตย์สุจริตในการทำข้อสอบและปฏิบัติตามกฎเกณฑ์การสอบอย่างเคร่งครัด
8. ประยุกต์แนวทางการพัฒนาแบบเศรษฐกิจพอเพียงในเรื่องการประหยัดอดออมในการใช้อุปกรณ์อย่างรู้คุณค่า

การสอบปลายภาค (Final Exam) จะวัดทักษะ 3 ด้านหลักดังนี้:
1. **Code Reading (30%)**: วัดทักษะการอ่านและทำความเข้าใจโค้ด ตัวอย่างเช่น:
   - การทำงานของ `useCallback` เพื่อรักษา Reference ของฟังก์ชัน
   - การใช้งาน Dependency Array `[]` ใน `useEffect`
   - การทำงานของบล็อก `finally` ใน `try-catch` ซึ่งจะทำงานเสมอเพื่อปิด Loading state
2. **Code Writing (40%)**: วัดทักษะการลงมือเขียนโค้ดจริง เช่น:
   - การสร้าง TypeScript Interface แบบกำหนด Type ครบถ้วน
   - การสร้าง React Component และใช้งาน Hooks พื้นฐาน
   - การใช้งาน Axios เพื่อดึงข้อมูล (Fetch API) และจัดการ State
3. **Conceptual (30%)**: วัดความเข้าใจเชิงทฤษฎี ตัวอย่างเช่น:
   - ความแตกต่างระหว่าง Props Drilling (ส่งข้อมูลผ่านหลายชั้น) และ Context API (เข้าถึงข้อมูลได้โดยตรงจากทุกที่)
   - การทำงานของ JWT และ Axios Interceptor
