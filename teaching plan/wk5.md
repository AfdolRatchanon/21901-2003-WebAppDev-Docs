หน่วยที่ (Unit)       3		ชื่อหน่วย (Name of Unit)     UI + Forms (Tailwind CSS และ Controlled Forms)
หัวเรื่อง (Sub Unit)/งาน (JOB) การปรับแต่งหน้าตาเว็บด้วย Tailwind CSS และการจัดการฟอร์มเบื้องต้น

1.  สาระสำคัญ (Concept) 
	การสร้างส่วนติดต่อผู้ใช้ (UI) ที่สวยงามและตอบสนองได้ดี (Responsive) เป็นสิ่งจำเป็นในการพัฒนาเว็บแอปพลิเคชัน การนำ Tailwind CSS ซึ่งเป็น Utility-first CSS Framework มาช่วยจะทำให้จัดรูปแบบหน้าจอได้รวดเร็วและเป็นระบบ นอกจากนี้ การรับข้อมูลจากผู้ใช้งานผ่านฟอร์ม (Forms) ใน React จะใช้หลักการ Controlled Forms โดยนำข้อมูลไปผูกกับตัวแปร State เพื่อให้ React สามารถควบคุมและดึงค่าข้อมูลจาก Input ได้อย่างถูกต้อง พร้อมทั้งใช้ TypeScript ควบคุม FormEvent ให้ตรงตามประเภท

2.  สมรรถนะหลัก/ย่อย (Unit of Competence / Element of Competence)
1. มีความเข้าใจโครงสร้างและการใช้คลาสของ Tailwind CSS ในการจัดหน้าจอ
2. มีทักษะในการออกแบบหน้าจอให้รองรับหลากหลายอุปกรณ์ (Responsive Grid)
3. มีความเข้าใจหลักการของ Controlled Forms ใน React
4. มีทักษะในการจัดการ Event ของ Form ด้วย TypeScript

3.  จุดประสงค์เชิงพฤติกรรม (Behavioral Objective)
1. ใช้งาน Tailwind CSS ร่วมกับ Vite เพื่อจัดรูปแบบหน้าเว็บได้
2. ประยุกต์ใช้ Responsive Grid เพื่อจัดเรียง Component ได้อย่างสวยงาม
3. สร้าง Controlled Form โดยใช้ `value` และ `onChange` ผูกกับ State ได้อย่างถูกต้อง
4. จัดการและระบุประเภท TypeScript สำหรับ `React.ChangeEvent` และ `React.FormEvent` ได้
5. เตรียมเครื่องคอมพิวเตอร์และสภาพแวดล้อมเพื่อการเรียนได้
6. เปิดโปรแกรมหรือเอกสารเพื่อศึกษาเนื้อหาควบคู่ได้อย่างถูกต้อง
7. สรุปเนื้อหาได้
8. แสดงความสนใจต่องานที่ได้รับมอบหมายได้เป็นอย่างดีเมื่อครูมอบหมายงานให้ทำ
9. ประยุกต์แนวทางการพัฒนาแบบเศรษฐกิจพอเพียงในเรื่องการประหยัดอดออมในการใช้อุปกรณ์อย่างรู้คุณค่า
10. ประยุกต์ใช้เป็นแนวทางในการดำเนินชีวิตอย่างสุจริตได้

การปรับแต่งหน้าตาเว็บด้วย Tailwind CSS และการจัดการฟอร์มเบื้องต้น
- **Tailwind CSS** เป็น Utility-first CSS framework ซึ่งให้คลาส (class) จำนวนมากที่มีหน้าที่เฉพาะเจาะจง (เช่น `text-center`, `mt-4`, `p-2`) ทำให้เราสามารถเขียนสไตล์ลงไปใน HTML/JSX ได้โดยตรง ไม่ต้องสลับไปมากับไฟล์ CSS ทำให้พัฒนาได้อย่างรวดเร็วและปรับเปลี่ยนขนาดหน้าจอ (Responsive) ได้ง่ายด้วยคำสั่ง `md:`, `lg:`
- **Controlled Forms** ใน React คือการทำให้ Input ของ Form อยู่ภายใต้การควบคุมของ React State โดยเราจะกำหนดให้ `value` ของ Input มีค่าเท่ากับ State นั้น และใช้ Event `onChange` เพื่อคอยอัปเดต State ทันทีที่ผู้ใช้พิมพ์
- **TypeScript & Event Handling** เมื่อมีการรับข้อมูลจาก Input จำเป็นต้องระบุ Type ให้กับ Event เพื่อให้ระบบรู้ว่าเรากำลังทำงานกับสิ่งใด เช่น ใช้ `React.ChangeEvent<HTMLInputElement>` สำหรับช่องกรอกข้อมูลปกติ และ `React.FormEvent` สำหรับเหตุการณ์การกดยืนยัน (Submit Form)
