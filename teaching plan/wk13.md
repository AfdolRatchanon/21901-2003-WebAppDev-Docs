หัวเรื่อง (Sub Unit)/งาน (JOB) โครงสร้าง JWT, Protected Routes และ Socket.io

1.  สาระสำคัญ (Concept) 
	การพัฒนาเว็บแอปพลิเคชันที่มีระบบสมาชิกจะต้องให้ความสำคัญกับระบบความปลอดภัย (Security) โทเค็น (Token) แบบ JWT ถือเป็นมาตรฐานสากลในการตรวจสอบสิทธิ์ ซึ่งสามารถนำมาใช้งานร่วมกับไลบรารี React Router เพื่อสร้าง Protected Routes ที่ป้องกันไม่ให้ผู้ใช้ที่ยังไม่ล็อกอินเข้าถึงหน้าสำคัญได้ นอกจากนี้ เพื่อให้หน้าเว็บดูทันสมัยและโต้ตอบได้ทันที การประยุกต์ใช้ WebSocket อย่าง Socket.io เพื่อรับเหตุการณ์อัปเดตแบบเรียลไทม์ (Real-time) จากเซิร์ฟเวอร์ จะช่วยสร้างประสบการณ์การใช้งานที่ดีเยี่ยม

2.  สมรรถนะหลัก/ย่อย (Unit of Competence / Element of Competence)
1. มีความเข้าใจโครงสร้างของ JSON Web Token (JWT) และกระบวนการเข้ารหัส
2. มีความเข้าใจหลักการจัดการเส้นทาง (Routing) และการป้องกันหน้าเว็บ (Protected Routes) ใน React
3. มีความเข้าใจหลักการทำงานของ Socket.io สำหรับการเชื่อมต่อแบบ Real-time
4. มีทักษะในการใช้ `jwt-decode` ถอดรหัสและตรวจสอบวันหมดอายุของ Token

3.  จุดประสงค์เชิงพฤติกรรม (Behavioral Objective)
1. อธิบายโครงสร้างทั้ง 3 ส่วนของ JWT (Header, Payload, Signature) ได้
2. ตรวจสอบการหมดอายุของ Token ด้วยการเขียนโค้ดได้อย่างถูกต้อง
3. ประยุกต์ใช้ React Router ในการสร้างเงื่อนไข Protected Route สำหรับควบคุมสิทธิ์การเข้าถึงได้
4. อธิบายและเชื่อมต่อระบบการรับข้อมูลเหตุการณ์ Real-time (Socket.io) ร่วมกับ React Hook ได้
5. เตรียมเครื่องคอมพิวเตอร์และสภาพแวดล้อมเพื่อการเรียนได้
6. เปิดโปรแกรมหรือเอกสารเพื่อศึกษาเนื้อหาควบคู่ได้อย่างถูกต้อง
7. สรุปเนื้อหาได้
8. แสดงความสนใจต่องานที่ได้รับมอบหมายได้เป็นอย่างดีเมื่อครูมอบหมายงานให้ทำ
9. ประยุกต์แนวทางการพัฒนาแบบเศรษฐกิจพอเพียงในเรื่องการประหยัดอดออมในการใช้อุปกรณ์อย่างรู้คุณค่า
10. ประยุกต์ใช้เป็นแนวทางในการดำเนินชีวิตอย่างสุจริตได้

โครงสร้าง JWT, Protected Routes และ Socket.io
- **JSON Web Token (JWT)** เป็นมาตรฐานการสร้างรหัสอ้างอิงประกอบด้วย Header (ชนิดของอัลกอริทึม), Payload (ข้อมูลต่างๆ เช่น User ID, วันหมดอายุ), และ Signature (ลายเซ็นยืนยันความถูกต้อง) ข้อดีคือเราสามารถดึงข้อมูลใน Payload มาใช้ได้เลยโดยไม่ต้องไปถาม Database ทุกครั้ง
- **Protected Routes** คือการสร้าง Component ตัวแทนใน React Router ที่คอยดักเช็คก่อนว่าผู้ใช้มีสิทธิ์ไหม ถ้ามีก็จะให้ผ่านไปยัง Component ลูก (ใช้ `{children}`) ถ้าไม่มีก็จะดีดผู้ใช้ออกไปที่หน้าล็อกอินโดยใช้ `<Navigate />`
- **Socket.io** เป็นไลบรารีสำหรับการสื่อสารผ่านโปรโตคอล WebSocket ที่สามารถรับส่งข้อมูลได้แบบ Real-time โดยไม่ต้องให้เบราว์เซอร์ส่ง HTTP Request ไปถามหาบ่อยๆ (Polling) ทำให้เหมาะมากกับระบบแจ้งเตือนต่างๆ
