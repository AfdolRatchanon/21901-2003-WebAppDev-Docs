แผนการสอนแบบฐานสมรรถนะ (Competency-based Teaching Plan)
สัปดาห์ที่ (Week)     3

รหัสวิชา (Code)     21901-2003  	วิชา (Subject)     การพัฒนาเว็บแอปพลิเคชัน                                                        
หน่วยที่ (Unit)       2		ชื่อหน่วย (Name of Unit)     ฟังก์ชันและข้อมูล (useState, useEffect และ Data Model)
หัวเรื่อง (Sub Unit)/งาน (JOB) การจัดการสถานะข้อมูล วงจรชีวิตคอมโพเนนต์ และ Custom Hooks

1.  สาระสำคัญ (Concept) 
	ในการพัฒนาเว็บแอปพลิเคชันด้วย React การจัดการข้อมูลที่สามารถเปลี่ยนแปลงได้ (State) ถือเป็นหัวใจสำคัญ โดยใช้ Hook ที่ชื่อว่า `useState` เพื่อเก็บและอัปเดตข้อมูล และใช้ `useEffect` สำหรับจัดการ Side Effects หรือการทำงานที่อยู่นอกเหนือจากการแสดงผล (เช่น การดึงข้อมูล API หรือการจับเวลา) นอกจากนี้ การแยกการทำงานซับซ้อนออกไปเป็น Custom Hooks ยังช่วยให้โค้ดเป็นระเบียบและนำกลับมาใช้ซ้ำได้ การใช้งานควบคู่กับ TypeScript ในการนิยามโครงสร้างข้อมูล (Data Model) จะช่วยเพิ่มความปลอดภัยและลดข้อผิดพลาดในการรับส่งข้อมูล

2.  สมรรถนะหลัก/ย่อย (Unit of Competence / Element of Competence)
1. มีความเข้าใจหลักการทำงานของ State และการอัปเดตข้อมูลด้วย useState
2. มีความเข้าใจเรื่อง Side Effects และวงจรชีวิตของ Component ผ่าน useEffect
3. มีความเข้าใจในการสร้างและการใช้งาน Custom Hooks
4. มีทักษะในการออกแบบ Data Model ด้วย Types และ Interfaces ใน TypeScript

3.  จุดประสงค์เชิงพฤติกรรม (Behavioral Objective)
1. อธิบายและใช้งาน useState เพื่อเก็บและเปลี่ยนแปลงข้อมูล (State) ได้อย่างถูกต้อง
2. ใช้งาน useEffect เพื่อจัดการ Side Effects และอธิบาย Dependency Array ได้
3. สร้าง Custom Hook เพื่อแยกการจัดการข้อมูลออกจาก UI Component ได้อย่างถูกต้อง
4. ออกแบบและกำหนด Types/Interfaces สำหรับ Data Model ได้
5. เตรียมเครื่องคอมพิวเตอร์และสภาพแวดล้อมเพื่อการเรียนได้
6. เปิดโปรแกรมหรือเอกสารเพื่อศึกษาเนื้อหาควบคู่ได้อย่างถูกต้อง
7. สรุปเนื้อหาได้
8. แสดงความสนใจต่องานที่ได้รับมอบหมายได้เป็นอย่างดีเมื่อครูมอบหมายงานให้ทำ
9. ประยุกต์แนวทางการพัฒนาแบบเศรษฐกิจพอเพียงในเรื่องการประหยัดอดออมในการใช้อุปกรณ์อย่างรู้คุณค่า
10. ประยุกต์ใช้เป็นแนวทางในการดำเนินชีวิตอย่างสุจริตได้
5.  กิจกรรมการเรียนรู้ (Teaching / Learning Activities)
	-  ทบทวนเนื้อหาจากสัปดาห์ที่ผ่านมา และอธิบายการเชื่อมโยงระบบ MIAP เข้าสู่เรื่องการจัดการข้อมูล
	เรื่องที่/งานที่ (Sub Topic/Job)  :   ฟังก์ชันและข้อมูล
	หัวข้อที่/งานที่ (Sub  Unit/Main Job)  :  การจัดการสถานะข้อมูล วงจรชีวิตคอมโพเนนต์ และ Custom Hooks
	ขั้นนำเข้าสู่บทเรียน  (Motivation)  
1. ครูแสดงตัวอย่างเว็บแอปพลิเคชันที่มีระบบตะกร้าสินค้าหรือจำนวนแจ้งเตือนที่เปลี่ยนแปลงได้ตลอดเวลา
2. ครูถามนักเรียนว่าข้อมูลที่เปลี่ยนไปเรื่อยๆ ตามการกระทำของผู้ใช้ (เช่น การคลิก) มีวิธีการเขียนด้วยตัวแปรปกติได้หรือไม่ และทำไมหน้าจอถึงไม่อัปเดต
3. ครูสรุปเข้าเรื่องความจำเป็นของการใช้ `useState` และ `useEffect` ใน React
	ขั้นการให้เนื้อหาความรู้  (Information)  
1. ขอบข่ายเนื้อหาหลัก
useState (State, Setter, Re-render): การเก็บข้อมูลและการสั่งให้หน้าจออัปเดต (Re-render)
useEffect (Side Effects): การจัดการการทำงานหลังจากการแสดงผลเสร็จสิ้น และการควบคุมด้วย Dependency Array
Custom Hooks (useEquipments): การสร้าง Hook แบบกำหนดเองเพื่อจัดการ State ภายใน
Data Model: การกำหนด Types, Interfaces และ Union Types สำหรับการใช้งาน
2. แนวทางการจัดกิจกรรมการสอน
2.1 จัดเตรียมเนื้อหาให้นักศึกษา (wk2-content1-state, wk2-content2-effect, wk2-content3-hooks, wk2-content4-types)
2.2 ถามและตอบคำถามนักเรียนพร้อมกับบรรยายเนื้อหาและยกตัวอย่าง
2.3 สาธิตการเขียนและใช้งาน useState และ useEffect แบบง่ายๆ เพื่อให้นักเรียนเห็นการเปลี่ยนแปลงบนหน้าจอ
2.4 อธิบายหรือสาธิตการทำงานซ้ำเมื่อนักเรียนทำไม่ทัน
ขั้นการประยุกต์เนื้อหา  (Application) 
1. ให้ นศ. ศึกษาเนื้อหาและทดลองสร้าง State เก็บข้อมูลตัวเลขหรือข้อความ
2. ให้ นศ. ทดลองใช้ useEffect ในการแสดงข้อความบน Console เมื่อค่าใน State เปลี่ยนแปลง
3. ให้ นศ. ทดลองสร้าง Interface กำหนดโครงสร้างอุปกรณ์ (Equipment)
		-  สุ่มถามผู้เรียนว่าเมื่อไหร่ควรใช้ `useState` และเมื่อไหร่ควรใช้ `useEffect` รวมถึงประโยชน์ของการนำ Logic ไปเก็บไว้ใน Custom Hooks

	ขั้นตรวจผลสำเร็จ  (Progress)

- การสรุปสาระสำคัญลงในสมุดจด  ครูผู้สอนตรวจสอบจากการถาม-ตอบของผู้เรียน

การจัดการสถานะข้อมูล วงจรชีวิตคอมโพเนนต์ และ Custom Hooks
- **useState** คือ React Hook ที่ช่วยให้ Component สามารถเก็บข้อมูลและแก้ไขข้อมูล (State) ภายในตัวมันเองได้ และเมื่อข้อมูลนี้เปลี่ยนแปลง Component จะทำการ Re-render หน้าจอให้แสดงผลข้อมูลใหม่โดยอัตโนมัติ การใช้ร่วมกับ TypeScript เช่น `useState<number>(0)`
- **useEffect** ใช้สำหรับจัดการสิ่งต่างๆ ที่เกิดขึ้นภายหลังจากการแสดงผลหน้าจอแล้ว หรือที่เรียกว่า Side Effects เช่น การเรียกข้อมูลจาก API, การอัปเดต Document Title หรือการทำงานกับ Timer โดยจะมี Dependency Array ใช้ควบคุมว่าจะให้ทำงานเมื่อตัวแปรใดมีการเปลี่ยนแปลง
- **Custom Hooks** เป็นการนำการทำงานแบบ Logic ที่อาจมี useState หรือ useEffect ที่เขียนไว้หลายบรรทัด นำไปรวมไว้ในฟังก์ชันชื่อเดียว (ขึ้นต้นด้วย `use` เสมอ) เพื่อความเป็นระเบียบและทำให้หน้านั้นเรียกใช้งานได้ง่ายขึ้น เช่น `useEquipments()`
- **Data Model** คือการนิยามโครงสร้างข้อมูล เพื่อให้ระบบทำงานได้เสถียร โดยใช้ `interface` สำหรับ Object หรือ `type` สำหรับ Union Types ใน TypeScript ช่วยป้องกันปัญหาข้อมูลสูญหาย หรือพิมพ์ผิดระหว่าง Component
