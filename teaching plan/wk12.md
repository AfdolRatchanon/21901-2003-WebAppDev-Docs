รหัสวิชา (Code)     21901-2003  	วิชา (Subject)     การพัฒนาเว็บแอปพลิเคชัน                                                        
หน่วยที่ (Unit)       6		ชื่อหน่วย (Name of Unit)     Cookies & Session (การจัดการเซสชันและปฏิบัติงาน Lab)
หัวเรื่อง (Sub Unit)/งาน (JOB) ปฏิบัติงาน Lab: LoginPage และ Auth Flow

1.  สาระสำคัญ (Concept) 
	การประยุกต์ใช้ความรู้ในเรื่อง Context API, Forms, Validation และ localStorage นำมาประกอบกันเพื่อสร้างหน้าจอสำหรับเข้าสู่ระบบ (LoginPage) ในสัปดาห์นี้จะเป็นการทำงานปฏิบัติ (Lab) อย่างเต็มรูปแบบ เพื่อพัฒนาระบบยืนยันตัวตน (Authentication Flow) ให้สมบูรณ์ ตั้งแต่รับข้อมูลอีเมลและรหัสผ่านจากผู้ใช้งาน ตรวจสอบเงื่อนไข ส่งข้อมูลไปตรวจสอบกับ API รับ Token กลับมาเก็บบันทึก และเปลี่ยนสถานะใน Context เพื่อให้ระบบจดจำผู้ใช้ได้ ถือเป็นหัวใจสำคัญของเว็บแอปพลิเคชันทุกประเภท

2.  สมรรถนะหลัก/ย่อย (Unit of Competence / Element of Competence)
1. มีทักษะในการออกแบบและพัฒนาหน้าจอ LoginPage ด้วย Tailwind CSS
2. มีทักษะในการสร้างฟอร์มเพื่อส่งข้อมูลยืนยันตัวตน (Login) และจัดการ FormEvent ได้
3. มีความสามารถในการประยุกต์ใช้ Context API ร่วมกับ localStorage เพื่อเก็บเซสชัน
4. มีเจตคติและกิจนิสัยที่ดีในการปฏิบัติงานด้วยความละเอียดรอบคอบ รับผิดชอบ

3.  จุดประสงค์เชิงพฤติกรรม (Behavioral Objective)
1. สร้าง Component หน้าจอ LoginPage ด้วย UI ที่สวยงามและรองรับ Responsive ได้
2. จัดการฟอร์มรับข้อมูลและแสดงข้อผิดพลาด (Error Validation) จากการล็อกอินได้
3. เขียนฟังก์ชันเรียกใช้งาน API เพื่อล็อกอิน และนำ Token ไปบันทึกลง localStorage ได้อย่างถูกต้อง
4. ปฏิบัติงานตามนโยบาย Lab โดยการแสดงชื่อและรหัสนักเรียนใน `<footer>` บนหน้าเว็บได้
5. ส่งงานโดยการ Push โค้ดขึ้น GitHub Repository ส่วนตัวและเขียนสรุปได้อย่างถูกต้อง
6. ประเมินผลงานและหาข้อผิดพลาดที่พบระหว่างการทำงานได้
7. แสดงความสนใจต่องานที่ได้รับมอบหมายได้เป็นอย่างดีเมื่อครูมอบหมายงานให้ทำ
8. ประยุกต์แนวทางการพัฒนาแบบเศรษฐกิจพอเพียงในเรื่องการประหยัดอดออมในการใช้อุปกรณ์อย่างรู้คุณค่า
9. ประยุกต์ใช้เป็นแนวทางในการดำเนินชีวิตอย่างสุจริตได้
5.  กิจกรรมการเรียนรู้ (Teaching / Learning Activities)
	-  ทบทวนเรื่อง localStorage และ Axios Interceptor จากสัปดาห์ที่ 11

	ขั้นนำเข้าสู่บทเรียน  (Motivation)  
1. ครูสาธิตระบบเบิก-จ่ายอุปกรณ์เวอร์ชันสมบูรณ์ และแสดงให้เห็นว่าบางหน้าเข้าไม่ได้หากไม่ได้ล็อกอิน
2. ครูถามนักเรียนถึงองค์ประกอบที่ต้องมีในหน้าจอ Login (เช่น ช่องกรอก, ปุ่ม, การแจ้งเตือน)
3. ครูสรุปเข้าเรื่องกระบวนการทำ Lab เพื่อสร้างหน้า LoginPage และเชื่อมโยง Flow ทั้งหมดเข้าด้วยกัน
	ขั้นการให้เนื้อหาความรู้  (Information)  
1. ขอบข่ายเนื้อหาหลัก

Feedback: การแสดง Loading State ระหว่างรอเซิร์ฟเวอร์ และการแสดง Error Message หากรหัสผ่านผิด
2. แนวทางการจัดกิจกรรมการสอน

2.3 สาธิตการเชื่อมโยงข้อมูลฟอร์มเข้ากับ AuthContext เพื่อให้นักเรียนเห็นการทำงานเป็นระบบ
2.4 อธิบายกระบวนการตรวจเช็ค Token บนแท็บ Application เพื่อยืนยันการบันทึก

ปฏิบัติงาน Lab: LoginPage และ Auth Flow
- **การเตรียมหน้าจอ LoginPage** เป็น Component ที่รวมการทำ Form (Controlled Forms ด้วย `value` + `onChange`), การออกแบบ UI ด้วย Tailwind CSS, และการแจ้งเตือน Validation หากผู้ใช้พิมพ์ข้อมูลไม่ครบถ้วน
- **Auth Flow (วงจรการล็อกอิน)** เริ่มตั้งแต่เมื่อกดปุ่ม Submit ข้อมูลจะถูกส่งไปยังฟังก์ชันใน AuthContext โดยมีการเช็ค `try-catch` ระหว่างรอก็แสดงผล "Loading..." หากอีเมล/รหัสผ่านผิด API จะคืนค่า Error ให้ระบบตั้งค่า State นำข้อความมาโชว์ หากล็อกอินสำเร็จ API จะส่ง Token มา
- **การรวมระบบ** เมื่อ AuthContext ได้รับ Token แล้วจะบันทึกลง `localStorage` และตั้งค่าตัวแปรอัปเดตสถานะให้ระบบรู้ว่า "ผู้ใช้นี้เข้าสู่ระบบแล้ว" จากนั้นจะพาย้ายหน้า (Redirect) ไปยังหน้าระบบหลัก ทำให้แอปพลิเคชันมีชีวิตและสมบูรณ์ยิ่งขึ้น
