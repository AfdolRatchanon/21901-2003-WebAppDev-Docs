1.  สาระสำคัญ (Concept) 
	การประยุกต์ใช้ความรู้ทางทฤษฎีในเรื่อง State และ Data Model มาปฏิบัติงานจริง โดยใน Lab นี้จะเป็นการนำ `useState` มาใช้จัดการข้อมูลในลักษณะของกลุ่มข้อมูล (Array of Objects) ซึ่งเรียกว่า Mock Data ที่จำลองมาจากระบบจริง นักเรียนจะได้ฝึกนำโครงสร้างข้อมูล (Data Model) เข้ามาช่วยจัดรูปแบบข้อมูลให้เป็นมาตรฐาน การส่งผ่าน Mock Data ไปแสดงผลร่วมกับ Component การ์ดอุปกรณ์ (EquipmentCard) ด้วยการใช้ `.map()` เพื่อให้แสดงรายการอุปกรณ์ทั้งหมดได้อย่างถูกต้องและเป็นแบบแผนเพื่อการต่อยอดเชื่อมต่อกับฐานข้อมูลในอนาคต

2.  สมรรถนะหลัก/ย่อย (Unit of Competence / Element of Competence)
1. มีทักษะในการพัฒนาเว็บแอปพลิเคชันโดยจัดการกลุ่มข้อมูล (Array) ให้อยู่ใน State ได้
2. มีทักษะในการนำ Mock Data มาแสดงผลผ่าน Component แบบวนซ้ำ (.map())
3. มีความสามารถในการประยุกต์ใช้งาน Interface ร่วมกับ State ใน TypeScript
4. มีเจตคติและกิจนิสัยที่ดีในการปฏิบัติงานด้วยความละเอียดรอบคอบ รับผิดชอบ

3.  จุดประสงค์เชิงพฤติกรรม (Behavioral Objective)
1. สร้างและจัดการ Array of Objects ด้วย useState ได้อย่างถูกต้อง
2. นำข้อมูลจาก State มาแสดงผลโดยวนซ้ำด้วย `.map()` ได้
3. ใช้งาน Interface เข้ามากำกับความถูกต้องของ Mock Data ได้
4. ปฏิบัติงานตามนโยบาย Lab โดยแสดงชื่อและรหัสนักเรียนใน `<footer>`
5. ส่งงานโดยการ Push โค้ดขึ้น GitHub Repository ส่วนตัวและเขียนสรุปได้อย่างถูกต้อง
6. ประเมินผลงานและหาข้อผิดพลาด (Error) ที่พบระหว่างการทำงานได้
7. แสดงความสนใจต่องานที่ได้รับมอบหมายได้เป็นอย่างดีเมื่อครูมอบหมายงานให้ทำ
8. ประยุกต์แนวทางการพัฒนาแบบเศรษฐกิจพอเพียงในเรื่องการประหยัดอดออมในการใช้อุปกรณ์อย่างรู้คุณค่า
9. ประยุกต์ใช้เป็นแนวทางในการดำเนินชีวิตอย่างสุจริตได้

- **Mock Data** คือ ข้อมูลจำลองที่สร้างขึ้นมาใช้งานเพื่อการทดสอบระหว่างการพัฒนาระบบ ซึ่งโดยทั่วไปอาจกำหนดเป็นรูปแบบ Array ของ Object เช่น สินค้า หรือข้อมูลอุปกรณ์ไอที ก่อนจะมีการดึงข้อมูลจริงจากฐานข้อมูล
- **useState with Array** การนำ State มาจัดเก็บ Mock Data Array ทำให้เราสามารถจัดการข้อมูลดังกล่าวและเปลี่ยนแปลงได้ เช่น การเพิ่ม ลบ หรือแก้ไข โดยหากกำหนด `useState<Equipment[]>` จะทำให้ระบบช่วยตรวจสอบว่าข้อมูลทั้งหมดตรงตามโครงสร้าง `Equipment` หรือไม่
- **การวนซ้ำข้อมูล (List)** ใน React เราใช้ JavaScript ฟังก์ชันอย่าง `.map()` ในการวนซ้ำตามจำนวน Array ที่เก็บไว้ใน State แล้วส่งคืนมาเป็น Component แต่ละตัว (เช่น EquipmentCard)
- **Keys** เมื่อมีการใช้ `.map()` เพื่อสร้าง List ใน React จะมีการบังคับใส่ `key` ซึ่งควรจะเป็นตัวระบุเฉพาะ (Unique Identifier เช่น `id`) เพื่อให้ React จดจำชิ้นส่วนที่ถูกสร้าง ช่วยเพิ่มประสิทธิภาพเวลาที่มีการเปลี่ยนแปลงข้อมูลใน List นั้นๆ
