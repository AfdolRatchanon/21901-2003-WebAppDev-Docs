หัวเรื่อง (Sub Unit)/งาน (JOB) การดึงข้อมูลด้วย Fetch API และการจัดการ Asynchronous

1.  สาระสำคัญ (Concept) 
	การพัฒนาเว็บแอปพลิเคชันให้สามารถทำงานร่วมกับข้อมูลจริงได้ จำเป็นต้องมีการเชื่อมต่อเพื่อดึงหรือส่งข้อมูลกับฝั่ง Backend (Server) ผ่านระบบที่เรียกว่า API (Application Programming Interface) โดยใน JavaScript จะใช้คำสั่ง `fetch` เพื่อดึงข้อมูล ซึ่งกระบวนการเหล่านี้จะทำงานแบบ Asynchronous (ไม่รอให้เสร็จก็ทำงานบรรทัดถัดไป) ทำให้ต้องมีการใช้ `Promise` ควบคู่กับการเขียนแบบ `async/await` และจัดการข้อผิดพลาด (Error) ที่อาจเกิดขึ้นระหว่างการดึงข้อมูลด้วยบล็อกคำสั่ง `try-catch`

2.  สมรรถนะหลัก/ย่อย (Unit of Competence / Element of Competence)
1. มีความเข้าใจหลักการทำงานของการเชื่อมต่อ API ผ่านโพรโทคอล HTTP
2. มีความเข้าใจการทำงานแบบ Asynchronous และ Promise ใน JavaScript
3. มีทักษะในการใช้คำสั่ง Fetch API และ async/await ในการดึงข้อมูล
4. มีทักษะในการจัดการข้อผิดพลาดด้วย Try-Catch Block

3.  จุดประสงค์เชิงพฤติกรรม (Behavioral Objective)
1. อธิบายความหมายและการทำงานของการเชื่อมต่อข้อมูลผ่าน API ได้
2. ใช้งานคำสั่ง Fetch API เพื่อดึงข้อมูลรูปแบบ JSON จาก Server ได้อย่างถูกต้อง
3. ประยุกต์ใช้ async / await เพื่อจัดการ Asynchronous Operation ได้
4. ใช้บล็อกคำสั่ง try-catch เพื่อดักจับและแสดงข้อผิดพลาด (Error Handling) ได้
5. เตรียมเครื่องคอมพิวเตอร์และสภาพแวดล้อมเพื่อการเรียนได้
6. เปิดโปรแกรมหรือเอกสารเพื่อศึกษาเนื้อหาควบคู่ได้อย่างถูกต้อง
7. สรุปเนื้อหาได้
8. แสดงความสนใจต่องานที่ได้รับมอบหมายได้เป็นอย่างดีเมื่อครูมอบหมายงานให้ทำ
9. ประยุกต์แนวทางการพัฒนาแบบเศรษฐกิจพอเพียงในเรื่องการประหยัดอดออมในการใช้อุปกรณ์อย่างรู้คุณค่า
10. ประยุกต์ใช้เป็นแนวทางในการดำเนินชีวิตอย่างสุจริตได้

1. ขอบข่ายเนื้อหาหลัก
Fetch API & Promises: การใช้คำสั่ง `fetch()` ดึงข้อมูลจาก URL ปลายทาง และสถานะของ Promise (Pending, Fulfilled, Rejected)
Async/Await: การเขียนโค้ด Asynchronous ให้อ่านง่ายขึ้นคล้ายแบบ Synchronous โดยใช้คำสั่ง `async` หน้าฟังก์ชัน และ `await` หน้า Promise
Try-Catch: การครอบคำสั่งที่มีโอกาสเกิด Error เพื่อไม่ให้โปรแกรมพัง และนำข้อมูล Error มาแสดงผล

การดึงข้อมูลด้วย Fetch API และการจัดการ Asynchronous
- **API (Application Programming Interface)** คือ ช่องทางที่ให้โปรแกรมหนึ่งสามารถสื่อสารหรือเรียกใช้งานข้อมูลจากอีกโปรแกรมหนึ่งได้ ในบริบทของเว็บแอปพลิเคชัน มักหมายถึงการดึงข้อมูลจาก Server รูปแบบ JSON
- **Fetch API & Promises** `fetch('URL')` เป็นคำสั่งมาตรฐานใน JavaScript ที่ใช้ร้องขอข้อมูล โดยจะทำงานแบบ Asynchronous ซึ่งจะคืนค่าเป็นก้อนข้อมูลอนาคตที่เรียกว่า Promise ทำให้โปรแกรมไม่ต้องหยุดรอและไปทำบรรทัดถัดไปได้
- **Async/Await** เป็นรูปแบบการเขียนโค้ดที่ครอบคำสั่ง Asynchronous ไว้ เพื่อให้มันทำงานเป็นลำดับเหมือนโค้ดปกติ (Synchronous) โดยใช้ `async` วางหน้าฟังก์ชันและใส่ `await` ก่อนเรียกคำสั่งที่คืนค่าเป็น Promise ทำให้โค้ดอ่านง่ายและเป็นระเบียบมากกว่าการเขียนต่อท้ายแบบ `.then()`
- **Try-Catch** เป็นเครื่องมือในการดักจับความผิดพลาด (Error Handling) โดยสิ่งที่จะทำงานในส่วน `try { }` หากมีปัญหาเกิดขึ้น โค้ดจะหยุดทำทันทีและกระโดดไปส่วน `catch (error) { }` เพื่อรับข้อความความผิดพลาดไปแสดงผลแทนการปล่อยให้ทั้งระบบล่ม
